How did you develop your code (e.g., what features have been added after first version)?

Event Driven Architectures
What in your code triggers events (e.g., GUI, buttons, timeout ...)?
  • GUI Buttons & Clicks: Investigation buttons trigger room searches; suspect cards trigger interrogation dialogues; clue cards trigger deduction board linking.
  • Form Submission: The cipher puzzle form submission (onsubmit) is intercepted with preventDefault() to validate answers via AJAX without page reloads.
  • Timeouts & Timers: A 60-second setInterval checks session validity; a 10-minute server inactivity timeout auto-logs out idle users.
  • Keyboard: Global Escape key event listener closes active dialog modals.
Interoperability
Do you use the API https://marcconrad.com/uob/tomato/api.php?
If no, where in your code do you demonstrate interoperability? What protocols do you use?
No, I use the University Banana API (https://marcconrad.com/uob/banana/api.php) through a secure PHP backend proxy (api/banana.php). The client browser issues asynchronous JavaScript fetch() requests to the PHP proxy, which communicates with Marc Conrad's cloud API over HTTPS using PHP cURL, exchanging structured JSON payloads. The proxy strips solutions before serving client requests to prevent DOM cheating.
Virtual Identity
How did you implement virtual identity in your code? (e.g., Passwords, Cookies, IP Numbers ...)
  • Passwords: User credentials are stored in MySQL with Bcrypt cryptographic hashing (password_hash() and password_verify() in api/auth.php).
  • Cookies & Sessions: Stateful sessions use PHP session cookies (PHPSESSID) hardened with HttpOnly and SameSite=Lax flags.
  • Inactivity Timeout: Strictly expires sessions after 10 minutes of inactivity, destroying server session data and cookies. Player progress is linked to user IDs in the database.
Any other interesting features:

  • Interactive Clue Deduction Board: Logic engine connects evidence pairs to unlock breakthrough deductions.
  • Branching Narrative Endings: 3 case endings calculated based on evidence gathered, interview clues, and deduction errors.
